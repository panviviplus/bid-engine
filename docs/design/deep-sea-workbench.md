# 标擎 · 深海智能工作台设计语言

## 设计目标

“深海智能工作台”服务于长时间、逐项核验的专业工作。界面以明亮纸面承载内容，以深海蓝承载控制与运行态，以金色标记 AI 活跃信号、证据定位和关键动作。动效表达真实状态，不模拟思考，不制造虚假进度。

## 语义色

| Token | 用途 | 色值 |
|---|---|---|
| `workbench.canvas` | 全局工作画布 | `#F2F5F7` |
| `workbench.paper` | 字段、条款和 PDF 纸面 | `#FFFFFF` |
| `workbench.control` | 顶部智控区、运行轨 | `#0B1B2B` |
| `workbench.controlRaised` | 深色区二级表面 | `#132B40` |
| `workbench.text` | 正文 | `#182636` |
| `workbench.muted` | 次要信息 | `#66798B` |
| `workbench.signal` | AI 运行信号 | `#D4A853` |
| `workbench.evidence` | 当前证据 | `#E5B94F` |

金色不用于大面积背景。成功、告警、错误继续使用统一语义色，并始终配合图标和文字。

## 排版与空间

- 正文使用 Inter / PingFang SC；金额、页码和进度使用等宽数字特性。
- 页面需要展示数据库时间时，统一格式化为 `YYYY-MM-DD HH:mm:ss`；接口仍传输可解析的标准时间值。
- 基础间距为 4px，内容密度以 8/12/16/24/32px 为主。
- 工作台表面圆角 12–16px；按钮 8–10px；状态标记为胶囊形。
- 桌面核验页默认字段/PDF 比例为 42/58，允许拖拽；移动端切换为两种全屏视图。

## 动效

- AI 运行信号：只在真实任务运行时沿阶段轨单向流动。
- 空间动效：面板、分类切换使用 240–300ms 的位移或短交叉淡入。
- 证据定位：当前证据一次扫描进入，其余证据只显示低强度轮廓。
- 操作反馈 80–200ms；禁止 `transition-all`、弹跳和无意义循环发光。
- `prefers-reduced-motion` 下取消空间位移与扫描，仅保留即时状态变化。

## 无障碍与状态

- 触控目标不小于 44px；关键动作不依赖 hover。
- Focus 使用清晰的 2px 品牌色轮廓，错误和键盘焦点即时出现。
- 列表和详情采用结构一致的骨架屏。
- 所有交互覆盖默认、Hover、Focus、Pressed、Disabled、Loading、Error、Success。

## 解析失败恢复

- 失败时阶段轨固定停留在失败节点，不继续播放运行信号。
- “从本阶段重试”复用已经成功的上游中间态，只清理失败阶段及其下游产物。
- “全局重试”创建新的不可变运行，从文档预处理重新开始；旧运行继续保留用于排障。
- 文档预处理、全文 Docling 索引、章节识别属于基础阶段，不允许跳过。
- 章节事实提取及其后的可降级阶段允许用户跳过；系统必须记录操作日志和未解决告警，最终状态只能是“完成 · 有告警”。
- 招标解析列表只提供单项目删除入口，不提供多选或批量删除。

## 响应式基线

- 列表页和核验页必须覆盖 320、375、414、768px，不产生页面级横向滚动。
- 320、375、414、768px 下，失败恢复动作纵向排列；字段/PDF 使用两种全屏视图，不压缩成双栏。
- 表格只允许在自身容器内横向滚动；项目卡指标在窄屏改为两列。
- 所有按钮标签保持单行，触控目标不小于 44px。
